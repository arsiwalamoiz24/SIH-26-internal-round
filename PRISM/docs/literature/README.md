# Literature corpus — ice evidence for PRISM's candidate regions

Papers backing [`../CANDIDATE_REGION_ICE_LITERATURE.md`](../CANDIDATE_REGION_ICE_LITERATURE.md)
and [`../LUNAR_SOUTH_POLE_ICE_VALIDATION_LITERATURE.md`](../LUNAR_SOUTH_POLE_ICE_VALIDATION_LITERATURE.md).

Downloaded 2026-08-27. **Only open-access / author-deposited / repository copies were
retrieved** — no paywall was bypassed. Publisher bot-walls (ScienceDirect, Wiley/AGU,
Nature, PNAS/PMC) blocked scripted download of several items even where the article is
nominally open access; those are listed under "Not downloaded" with a direct link for
manual retrieval through institutional access.

> **Repo note:** this folder is ~41 MB of PDFs and is **not** currently gitignored.
> Add `PRISM/docs/literature/*.pdf` to `.gitignore` if you don't want them committed.
